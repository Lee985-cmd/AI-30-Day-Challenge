## 📖 项目简介

这是一个**完整的 30 天 AI 学习计划**，专为零基础学习者设计。通过**费曼学习法**（用大白话解释复杂概念），带你从 Python 基础一路走到深度学习、计算机视觉、自然语言处理的前沿技术。

### ✨ 特色亮点

- 🎯 **零基础友好**: 不需要任何编程或数学背景
- 📚 **费曼学习法**: 每个概念都用通俗易懂的比喻解释
- 💻 **完整代码**: 500+ 可运行代码示例，复制即用
- 🎓 **实战导向**: 10+ 完整项目，从训练到部署
- 🌍 **中英双语**: 适合全球学习者
- 🔄 **持续更新**: 跟随最新 AI 技术发展

### 📊 学习成果

完成本教程后，你将能够：

✅ 熟练使用 Python 和 PyTorch  
✅ 理解和实现主流 ML/DL 算法  
✅ 构建图像识别、文本生成等 AI 应用  
✅ 部署模型到生产环境  
✅ 理解 AI 伦理和社会责任  
✅ 具备 AI 工程师的核心技能

- Python 3.7+
- 基本的计算机操作能力

### 安装依赖

4. **完成费曼输出** - 用自己的话解释学到的概念
5. **记录学习笔记** - 使用提供的模板

## 💻 代码示例

### 示例 1: 简单神经网络

```python
import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )
    
    def forward(self, x):
        return self.network(x)

# 使用
model = SimpleNet()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

### 示例 2: CNN 图像分类

```python
class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(64 * 16 * 16, 10)
    
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = x.view(-1, 64 * 16 * 16)
        return self.fc(x)
```

### 示例 3: Flask API 部署

```python
from flask import Flask, request, jsonify
import torch

app = Flask(__name__)
model = torch.load('model.pth')

@app.route('/predict', methods=['POST'])
def predict():
    data = request.json
    prediction = model(torch.tensor(data['input']))
    return jsonify({'prediction': prediction.tolist()})

if __name__ == '__main__':
    app.run(debug=True)
```

## 🎯 学习方法

### 费曼学习法四步

1. **选择概念** - 确定要学习的主题
2. **教授他人** - 用大白话解释给"12岁小孩"听
3. **发现盲点** - 卡壳的地方就是知识漏洞
4. **简化类比** - 创造生动的比喻和例子

### 每日学习流程

```
1. 阅读理论 (30-45分钟)
   ↓
2. 运行代码 (60-90分钟)
   ↓
3. 费曼输出 (30-45分钟)
   ↓
4. 总结反思 (15分钟)
```

### 学习建议

✅ **每天都要:**
- 亲手运行代码
- 做费曼输出练习
- 记录学习笔记

❌ **不要:**
- 只看不练
- 跳过基础直接看高级内容
- 追求速度忽视理解
