# 📚 扩展学习资源

## 🎓 在线课程

### 深度学习基础

1. **[Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning)** - Andrew Ng
   - 平台: Coursera
   - 难度: 初级-中级
   - 时长: 4 个月
   - 语言: 英文（有中文字幕）
   - 评价: ⭐⭐⭐⭐⭐

2. **[Fast.ai Practical Deep Learning](https://www.fast.ai/)**
   - 平台: Fast.ai
   - 难度: 中级
   - 特点: 实战导向，代码优先
   - 费用: 完全免费
   - 评价: ⭐⭐⭐⭐⭐

3. **[PyTorch Deep Learning](https://learn.pytorch.org/)**
   - 平台: PyTorch 官方
   - 难度: 初级-中级
   - 特点: 官方教程，权威可靠
   - 费用: 免费

### 计算机视觉

1. **[CS231n: CNN for Visual Recognition](http://cs231n.stanford.edu/)**
   - 学校: Stanford
   - 讲师: Fei-Fei Li, Andrej Karpathy
   - 难度: 中级-高级
   - 资料: 完全公开

2. **[Deep Learning for Computer Vision](https://www.udemy.com/course/deep-learning-computer-vision/)**
   - 平台: Udemy
   - 难度: 中级
   - 特点: 项目驱动

### 自然语言处理

1. **[CS224n: NLP with Deep Learning](http://web.stanford.edu/class/cs224n/)**
   - 学校: Stanford
   - 讲师: Christopher Manning
   - 难度: 中级-高级

2. **[Hugging Face NLP Course](https://huggingface.co/learn/nlp-course)**
   - 平台: Hugging Face
   - 难度: 初级-中级
   - 特点: 最新技术，实战性强
   - 费用: 免费

### 强化学习

1. **[Deep Reinforcement Learning](http://rail.eecs.berkeley.edu/deeprlcourse/)**
   - 学校: UC Berkeley
   - 讲师: Sergey Levine
   - 难度: 高级

2. **[Reinforcement Learning Specialization](https://www.coursera.org/specializations/reinforcement-learning)**
   - 平台: Coursera
   - 讲师: University of Alberta

## 📖 推荐书籍

### 入门级

1. **《Hands-On Machine Learning》** - Aurélien Géron
   - 难度: ⭐⭐
   - 特点: 实践导向，代码丰富
   - 语言: 英文（有中文版）
   - 推荐指数: ⭐⭐⭐⭐⭐

2. **《Deep Learning with Python》** - François Chollet
   - 难度: ⭐⭐
   - 特点: Keras 作者编写，通俗易懂
   - 语言: 英文（有中文版）
   - 推荐指数: ⭐⭐⭐⭐⭐

### 进阶级

3. **《Deep Learning》** - Ian Goodfellow
   - 难度: ⭐⭐⭐⭐
   - 特点: 理论基础扎实，"花书"
   - 语言: 英文（有中文版）
   - 推荐指数: ⭐⭐⭐⭐

4. **《Pattern Recognition and Machine Learning》** - Christopher Bishop
   - 难度: ⭐⭐⭐⭐⭐
   - 特点: 经典教材，数学严谨
   - 语言: 英文
   - 推荐指数: ⭐⭐⭐⭐

### 专项领域

5. **《Computer Vision: Algorithms and Applications》** - Richard Szeliski
   - 领域: 计算机视觉
   - 免费在线版: http://szeliski.org/Book/

6. **《Speech and Language Processing》** - Jurafsky & Martin
   - 领域: NLP
   - 免费在线版: https://web.stanford.edu/~jurafsky/slp3/

7. **《Reinforcement Learning: An Introduction》** - Sutton & Barto
   - 领域: 强化学习
   - 免费在线版: http://incompleteideas.net/book/the-book.html

## 📑 论文资源

### 论文搜索

1. **[ArXiv](https://arxiv.org/)**
   - 领域: 所有 AI 论文
   - 更新: 每日
   - 提示: 使用 `cs.LG`, `cs.CV`, `cs.CL` 等分类

2. **[Papers With Code](https://paperswithcode.com/)**
   - 特色: 论文 + 代码实现
   - 功能: SOTA 排行榜
   - 推荐: ⭐⭐⭐⭐⭐

3. **[ArXiv Sanity Preserver](http://www.arxiv-sanity.com/)**
   - 特色: ArXiv 论文筛选和排序
   - 创建者: Andrej Karpathy

4. **[Connected Papers](https://www.connectedpapers.com/)**
   - 特色: 论文引用关系图
   - 用途: 发现相关研究

## 🎯 学习路径建议

### 第 1-3 个月: 打好基础

**重点:**
- Python 编程
- 线性代数、概率统计基础
- 传统机器学习算法
- PyTorch 基础

**资源:**
- 本 30 天挑战教程
- Hands-On Machine Learning 前 10 章
- Kaggle Learn 微课程

### 第 4-6 个月: 深入学习

**选择一个方向:**
- 计算机视觉
- 自然语言处理
- 强化学习

**行动:**
- 完成专项课程
- 做 2-3 个项目
- 参加 Kaggle 竞赛
- 阅读经典论文

### 第 7-12 个月: 专业化

**目标:**
- 成为某个领域的专家
- 发表文章或博客
- 贡献开源项目
- 建立个人品牌

**行动:**
- 深入研究前沿技术
- 复现顶会论文
- 参与实际项目
- networking
