## 🔧 故障排除

### 问题 1：端口被占用

**错误信息：**
```
ERROR:    [Errno 10048] error while attempting to bind on address ('0.0.0.0', 8000)
```

**解决方法：**
```bash
# Windows：查找占用端口的进程
netstat -ano | findstr :8000

# 杀死进程（替换 PID）
taskkill /F /PID <PID>

# 或者修改端口
python ai_customer_service/api.py --port 8001
```

---

### 问题 2：缺少环境变量

**错误信息：**
```
ValueError: 请设置 OPENAI_API_KEY 环境变量
```

**解决方法：**
按照"第 2 步：配置 API Key"设置环境变量

---

### 问题 3：ChromaDB 初始化失败

**错误信息：**
```
Error initializing ChromaDB
```

**解决方法：**
```bash
# 删除旧的向量数据库
rm -rf chroma_db/

# 重新启动服务
python ai_customer_service/api.py
```

---

### 问题 4：Streamlit 无法启动

**错误信息：**
```
ModuleNotFoundError: No module named 'streamlit'
```

**解决方法：**
```bash
pip install streamlit==1.31.0
```

## 🔧 切换到国内大模型

### 智谱 AI（推荐）

**1. 安装智谱 AI SDK**
```bash
pip install zhipuai
```

**2. 修改 `ai_customer_service/knowledge_base.py`**

找到以下代码：
```python
from langchain.embeddings import OpenAIEmbeddings
self.embeddings = OpenAIEmbeddings()
```

修改为：
```python
from langchain.embeddings import HuggingFaceEmbeddings
# 使用本地 embedding 模型（无需 API Key）
self.embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
```

**3. 修改 `ai_customer_service/intent_agent.py` 和 `dialogue_agent.py`**

找到：
```python
from langchain.chat_models import ChatOpenAI
self.llm = ChatOpenAI(model="gpt-3.5-turbo")
```

修改为：
```python
from langchain.chat_models import ChatZhipuAI
import os

self.llm = ChatZhipuAI(
    model="glm-4",
    temperature=0.7,
    zhipuai_api_key=os.getenv("ZHIPUAI_API_KEY")
)
```

**4. 重启服务**
```bash
python ai_customer_service/api.py
```
