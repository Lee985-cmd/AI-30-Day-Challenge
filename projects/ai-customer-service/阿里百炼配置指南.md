## ⚙️ 配置环境变量

### Windows PowerShell

```powershell
# 临时设置（当前会话有效）
$env:DASHSCOPE_API_KEY="sk-your-api-key-here"

# 永久设置（推荐）
[System.Environment]::SetEnvironmentVariable("DASHSCOPE_API_KEY", "sk-your-api-key-here", "User")
```

### Windows CMD

```cmd
:: 临时设置
set DASHSCOPE_API_KEY=sk-your-api-key-here

:: 永久设置（需要管理员权限）
setx DASHSCOPE_API_KEY "sk-your-api-key-here"
```

### Linux/Mac

```bash
# 临时设置
export DASHSCOPE_API_KEY="sk-your-api-key-here"

# 永久设置（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export DASHSCOPE_API_KEY="sk-your-api-key-here"' >> ~/.bashrc
source ~/.bashrc
```

## 🎯 模型选择建议

### 意图识别（intent_agent.py）

**推荐模型：** `qwen-turbo`

**原因：**
- ✅ 速度快，延迟低
- ✅ 成本低，适合高频调用
- ✅ 意图分类任务简单，不需要最强模型

**修改方法：**
```python
self.llm = ChatTongyi(
    model="qwen-turbo",  # 或 qwen-plus
    temperature=0
)
```

---

### 对话生成（dialogue_agent.py）

**推荐模型：** `qwen-plus`

**原因：**
- ✅ 性能平衡，效果好
- ✅ 支持更长上下文
- ✅ 对话质量高

**修改方法：**
```python
self.llm = ChatTongyi(
    model="qwen-plus",  # 或 qwen-max
    temperature=0.7
)
```

## 🔧 常见问题

### Q1: 提示 "DASHSCOPE_API_KEY not found"

**解决方法：**
```bash
# 检查环境变量是否设置
echo $DASHSCOPE_API_KEY  # Linux/Mac
echo %DASHSCOPE_API_KEY%  # Windows CMD

# 重新设置
export DASHSCOPE_API_KEY="sk-your-key"
```

---

### Q2: 提示 "Invalid API Key"

**可能原因：**
1. API Key 复制错误（多了空格）
2. API Key 已过期或被删除
3. 账号未实名认证

**解决方法：**
- 重新创建 API Key
- 检查账号实名状态
- 确认 API Key 格式正确

---

### Q3: 提示 "Insufficient quota"

**原因：** 免费额度用完

**解决方法：**
1. 等待下个月重置
2. 充值获取更多额度
3. 切换到更便宜的模型（qwen-turbo）

---

### Q4: 响应速度慢

**可能原因：**
1. 网络问题
2. 模型负载高
3. 使用了 qwen-max

**解决方法：**
- 切换到 qwen-turbo 或 qwen-plus
- 检查网络连接
- 避开高峰期使用

---

### Q5: 中文效果不好

**解决方法：**
1. 确保使用最新版本 SDK
2. 尝试 qwen-plus 或 qwen-max
3. 优化 Prompt，使用清晰的中文指令
