# 示例问题列表

以下是一些可以用来测试 RAG 系统的问题：

## 基础问题

1. 什么是 RAG？
2. RAG 的核心原理是什么？
3. RAG 和传统的问答系统有什么区别？

## 技术问题

1. 什么是向量数据库？
2. ChromaDB 和 FAISS 有什么区别？
3. 什么是文本嵌入（embedding）？
4. 什么是相似度搜索？

## 应用问题

1. RAG 可以用于哪些场景？
2. 如何构建企业知识库？
3. 如何提高 RAG 系统的回答准确率？

## 配置问题

1. 如何调整文本块大小？
2. 如何更换向量数据库？
3. 如何使用本地模型？
4. 如何添加新的文档格式支持？

## 高级问题

1. 什么是 MMR 检索策略？
2. 如何实现混合检索（向量+关键词）？
3. 如何优化大规模文档的处理速度？
4. 如何实现流式输出？
