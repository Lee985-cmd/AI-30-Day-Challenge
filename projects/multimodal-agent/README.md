# 多模态智能客服 Agent

## 🎯 项目简介

这是一个支持**图像识别 + 智能对话**的多模态客服系统。

**⚠️ 重要说明：**
- 当前本地模型不支持真正的图片识别
- 采用**“图片描述+文本”模式**（用户描述图片，AI解答）
- 如需真正的多模态，请切换到支持视觉的模型（详见 `MULTIMODAL_SUPPORT.md`）

**核心特性：**
- ✅ 图像上传 - 展示产品和问题照片
- ✅ 智能对话 - 基于图文信息回答问题
- ✅ 产品识别 - 自动提取产品信息（需多模态模型）
- ✅ 问题诊断 - 分析描述并给出解决方案
- ✅ Web界面 - Streamlit构建的友好界面

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置模型

**方式一：使用本地模型（推荐）**

```powershell
# PowerShell（永久设置）
[System.Environment]::SetEnvironmentVariable("LOCAL_LLM_URL", "http://your-server:port/v1", "User")
```

**方式二：使用OpenAI API**

```powershell
# 设置 OpenAI API Key
[System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-xxx", "User")
```

### 3. 运行应用

```bash
streamlit run streamlit_app.py
```

浏览器会自动打开 http://localhost:8501

## 💡 功能说明

### ⚠️ 当前模式：图片描述+文本

由于本地模型不支持真正的图片识别，系统采用以下工作流程：

**使用步骤：**
1. 上传产品图片（作为参考）
2. **手动描述图片内容**
3. 提出问题
4. AI基于你的描述提供解答

**示例：**
```
上传图片: laptop.jpg
描述: 这是一台ThinkPad笔记本，屏幕左下角有裂纹，但能正常显示
问题: 需要更换屏幕吗？大概多少钱？

AI回答: 根据你的描述，屏幕出现裂纹通常需要更换整个屏幕总成...
```

### 1. 智能对话模式

**使用场景：** 用户有问题需要咨询

**操作流程：**
1. 上传产品图片
2. 输入问题（如："这个产品怎么使用？"）
3. AI分析图片并回答

**示例对话：**
```
用户：[上传电饭煲图片] 这个按钮是什么意思？
AI：从图片中我看到这是一个电饭煲的控制面板。这个按钮标有"保温"字样，
    它的作用是在煮饭完成后保持米饭的温度...
```

### 2. 产品识别模式

**使用场景：** 快速了解产品信息

**操作流程：**
1. 切换到"产品识别"模式
2. 上传产品图片
3. AI自动识别并提取信息

**输出内容：**
- 产品名称
- 品牌
- 颜色
- 特征
- 用途

### 3. 问题诊断模式

**使用场景：** 产品出现故障需要维修

**操作流程：**
1. 切换到"问题诊断"模式
2. 上传故障照片
3. 描述问题（可选）
4. AI分析问题并给出解决方案

**输出内容：**
- 问题识别
- 可能原因
- 解决步骤
- 预防建议

## 📊 应用场景

### 1. 电商售后

**场景：** 用户收到商品有问题

**传统方式：**
- 用户拍照 → 发给客服
- 客服人工查看 → 回复
- 耗时：30分钟 - 几小时

**Agent方式：**
- 用户拍照 → 上传系统
- AI自动分析 → 即时回复
- 耗时：< 10秒

**效率提升：** 180倍+

### 2. 技术支持

**场景：** 产品使用遇到问题

**案例：** 打印机卡纸

```
用户上传：打印机内部照片
AI分析：检测到纸张卡在滚轮处
解决方案：
1. 关闭打印机电源
2. 打开前盖
3. 轻轻拉出卡住的纸张
4. 检查是否有纸屑残留
5. 重新放入纸张测试
```

### 3. 质量检测

**场景：** 工业产品质检

**功能：**
- 自动识别产品缺陷
- 分类问题类型
- 生成质检报告
- 统计合格率

### 4. 教育辅导

**场景：** 学生作业批改

**功能：**
- 拍照上传作业
- AI识别题目
- 判断对错
- 给出讲解

## ⚠️ 注意事项

1. **图片质量**
   - 建议使用清晰的照片
   - 光线充足
   - 主体明确

2. **隐私保护**
   - 不要上传敏感信息
   - 图片仅用于本次对话
   - 不会保存到服务器

3. **模型限制**
   - 复杂图像可能识别不准确
   - 专业领域需要专业知识
   - 建议人工复核重要决策

4. **成本控制**
   - 多模态API调用成本较高
   - 建议优化图片大小
   - 缓存常用结果
