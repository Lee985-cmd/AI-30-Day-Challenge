## 💼 职业发展规划

### 职业路径选择

#### 路径1: ML Engineer (机器学习工程师)

**工作内容:**
- 模型训练和优化
- 数据管道构建
- 模型部署和维护
- 性能监控

**技能要求:**
- Python + PyTorch/TensorFlow
- SQL + 数据处理
- Docker + Kubernetes
- AWS/GCP
- MLOps

**薪资范围:**
- 初级: $80k-120k
- 中级: $120k-180k
- 高级: $180k-250k+

**学习路线:**
```
1. 巩固基础 (已完成 ✓)
2. 深入学习一个领域 (CV/NLP/RL)
3. 掌握 MLOps 工具
4. 做 2-3 个项目
5. 准备面试
6. 投递简历
```

#### 路径2: AI Researcher (AI 研究员)

**工作内容:**
- 阅读最新论文
- 提出新方法
- 实验验证
- 发表论文

**技能要求:**
- 扎实的数学基础
- 深入研究能力
- 编程实现能力
- 论文写作能力

**学历要求:**
- 通常需要 PhD
- 或 Master + 研究经验

**薪资范围:**
- Research Scientist: $150k-300k+
- Research Engineer: $120k-200k

**学习路线:**
```
1. 打好数学基础 (线性代数、概率、优化)
2. 深入阅读顶级会议论文 (NeurIPS, ICML, CVPR)
3. 复现经典论文
4. 找到研究兴趣点
5. 申请研究生/博士
6. 发表高质量论文
```

#### 路径3: AI Product Manager (AI 产品经理)

**工作内容:**
- 定义 AI 产品方向
- 协调技术和业务
- 用户需求分析
- 产品路线图

**技能要求:**
- 理解 AI 技术
- 商业敏感度
- 沟通能力
- 项目管理

**背景要求:**
- 技术背景 + 商业思维
- 或商业背景 + 技术学习

**薪资范围:**
- PM: $100k-160k
- Senior PM: $160k-220k
- Director: $220k-300k+

**学习路线:**
```
1. 理解 AI 技术边界 (已完成 ✓)
2. 学习产品管理方法论
3. 分析成功 AI 产品案例
4. 做 side project
5. 转岗或跳槽
```

#### 路径4: AI Consultant (AI 顾问)

**工作内容:**
- 为企业提供 AI 咨询
- 技术方案设计
- 可行性评估
- 实施指导

**技能要求:**
- 广泛的技术知识
- 行业理解
- 沟通能力
- 问题解决

**适合人群:**
- 喜欢多样性
- 善于沟通
- 快速学习

**薪资范围:**
- Consultant: $90k-150k
- Senior: $150k-250k
- Partner: $250k-500k+

**技术面试:**

4. **系统设计**: 设计一个推荐系统
5. **项目深挖**: 你的项目细节

**常见问题:**
```
1. 解释一下 Transformer 的 Self-Attention

```

**行为面试:**
