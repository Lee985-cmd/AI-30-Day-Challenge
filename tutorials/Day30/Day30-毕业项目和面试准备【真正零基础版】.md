### 技术面试题库

#### 机器学习基础

```python
"""
Q1: 过拟合和欠拟合的区别？怎么解决？

A: 
过拟合 (Overfitting):
- 现象：训练集表现好，测试集差
- 原因：模型太复杂，记住了噪声
- 解决:
  ✓ 增加数据
  ✓ 正则化 (L1/L2)
  ✓ Dropout
  ✓ 早停 (Early Stopping)
  ✓ 简化模型

欠拟合 (Underfitting):
- 现象：训练集和测试集都差
- 原因：模型太简单，学不到东西
- 解决:
  ✓ 增加模型复杂度
  ✓ 增加特征
  ✓ 减少正则化
  ✓ 训练更久


Q2: 偏差 - 方差权衡是什么？

A:
偏差 (Bias):
- 预测值与真实值的差异
- 反映模型的拟合能力
- 偏差大 → 欠拟合

方差 (Variance):
- 不同训练集下预测的变化
- 反映模型的稳定性
- 方差大 → 过拟合

权衡:
- 降低偏差会增加方差
- 降低方差会增加偏差
- 找平衡点


Q3: 交叉验证的原理？

A:
K 折交叉验证:
1. 把数据分成 K 份
2. 每次用 K-1 份训练，1 份验证
3. 重复 K 次，取平均

优点:
✓ 充分利用数据
✓ 评估更可靠
✓ 减少随机性

常用:
- K=5 或 K=10
- 分层抽样 (保持类别分布)


Q4: SVM 和逻辑回归的区别？

A:
相同点:
- 都是分类算法
- 都可以加核函数
- 都有正则化

不同点:
SVM:
- 最大化间隔
- 只关心支持向量
- 适合小样本
- 对异常值敏感

LR:
- 最大化似然
- 考虑所有样本
- 输出概率
- 适合大规模
"""
```

#### 深度学习

```python
"""
Q1: CNN 为什么适合图像处理？

A:
1. 局部连接
   - 图像的空间局部性
   - 减少参数

2. 权值共享
   - 同一个卷积核扫遍全图
   - 平移不变性

3. 层次化特征
   - 浅层：边缘、角点
   - 中层：纹理、图案
   - 深层：物体、部件


Q2: RNN 的梯度消失问题？怎么解决？

A:
问题:
- 反向传播时梯度连乘
- 序列太长，前面梯度消失
- 学不到长距离依赖

解决:
1. LSTM
   - 门控机制
   - 细胞状态
   - 长短期记忆

2. GRU
   - 简化版 LSTM
   - 更快

3. Transformer
   - Attention 机制
   - 并行计算
   - 彻底解决


Q3: BatchNorm 的作用？

A:
作用:
1. 加速收敛
   - 每层分布稳定
   - 可以用更大学习率

2. 防止过拟合
   - 有轻微正则化效果

3. 降低初始化敏感度
   - 不那么挑初始权重

原理:
- 对每个 batch 归一化
- 均值 0，方差 1
- 学习 scale 和 shift 参数

注意:
- 训练和推理不一样
- 推理用移动平均
"""
```
