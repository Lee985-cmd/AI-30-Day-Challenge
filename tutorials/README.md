1. **从 Day01 开始**
   ```bash

   ```

   - 然后按顺序学习 Q1-Q6

## 💡 学习建议

### 推荐流程
```
每天 2-3 小时：
1. Q0 复习 (20分钟)
   ↓
2. Q1-Q6 学习 (90-120分钟)
   - 阅读费曼输出
   - 运行代码
   - 理解原理
   ↓
3. 费曼输出练习 (30-45分钟)
   - 用自己的话解释
   - 创造比喻
   ↓
4. 查看完成报告 (15分钟)
   - 总结收获
   - 规划明天
```

### 关键点
- ✅ 每个问题都先用大白话理解
- ✅ 一定要亲手运行代码
- ✅ 尝试修改参数看效果
- ✅ 记录自己的理解和疑问
