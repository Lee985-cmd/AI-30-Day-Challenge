## 📚 Day23 核心知识点回顾

### 1. BERT 的本质

**BERT (Bidirectional Encoder Representations from Transformers)**
- 双向 Transformer 编码器
- 擅长理解类任务（分类、QA）
- 预训练 + 微调范式

### 2. BERT 的核心创新

**Masked Language Model (MLM):**
```
输入: "我 [MASK] 你"
输出: "爱"

替换策略:
- 80% 替换为 [MASK]
- 10% 替换为随机词
- 10% 保持不变
```

**Next Sentence Prediction (NSP):**
```
判断两个句子是否连续
学习句子间关系
```

### 3. 预训练的优势

| 方面 | 传统方法 | BERT |
|------|----------|------|
| 数据需求 | 100,000+ | 1,000-10,000 |
| 训练时间 | 数周 | 数小时 |
| 性能 | 85% | 94% |
| 泛化能力 | 一般 | 优秀 |

### 4. 大语言模型家族

**Encoder-only (理解类):**
- BERT
- RoBERTa
- ALBERT

**Decoder-only (生成类):**
- GPT-2
- GPT-3
- ChatGPT/GPT-4

**Encoder-Decoder (序列到序列):**
- T5
- BART

### 5. GPT 架构特点

```
GPT: Decoder-only 架构
- 自回归生成（逐个 token）
- 因果注意力掩码
- 单向上下文（只能看前面）
- 擅长生成任务
```

### 6. 提示工程基础

**好的提示设计:**
- 明确具体
- 提供上下文
- 指定格式
- 设定角色

**Few-shot Learning:**
```
例子1: 输入A → 输出B
例子2: 输入C → 输出D
测试: 输入E → ?
```

## 🔍 Day24 预习要点

### 文本生成的演进

1. **基于规则** (1980s)
   - if-then 逻辑
   - 专家系统
   - 死板不灵活

2. **统计模型** (1990s-2000s)
   - N-gram
   - 概率预测
   - 缺乏长距离依赖

3. **RNN/LSTM** (2010s)
   - 序列建模
   - 捕捉依赖关系
   - 训练慢，遗忘问题

4. **Transformer/GPT** (2018+)
   - 并行计算
   - 长距离依赖
   - 高质量生成

### GPT 的关键技术

1. **因果语言建模**
   - 预测下一个词
   - 自回归生成
   - 逐步扩展上下文

2. **生成策略**
   - Greedy Search
   - Beam Search
   - Top-k Sampling
   - Top-p (Nucleus) Sampling

3. **质量控制**
   - 温度参数
   - 重复惩罚
   - 长度控制

### Prompt Engineering 进阶

1. **Zero-shot**: 直接提问
2. **One-shot**: 给一个例子
3. **Few-shot**: 给多个例子
4. **Chain-of-Thought**: 思维链推理
5. **Role Prompting**: 设定角色
