## 📝 详细解答

### 知识点 1：监督 vs 无监督学习

**本质区别：**

🔹 **监督学习 = 有老师教**
```
特点：
→ 数据有标签（有标准答案）
→ 告诉模型什么是对的
→ 模型学着预测

例子 1：教小孩认动物
→ 给他看图片
→ 告诉他"这是猫""这是狗"
→ 他学会了就能认新的

例子 2：考试做题
→ 有标准答案
→ 做错了知道改
→ 越学越好

Week1 的监督学习算法：
✓ KNN（K 近邻）
✓ 决策树
✓ 随机森林
✓ SVM（支持向量机）
✓ 逻辑回归
```

🔹 **无监督学习 = 自己玩**
```
特点：
→ 数据没标签（没答案）
→ 让模型自己发现规律
→ 分组、降维等

例子 1：整理衣柜
→ 没人告诉你怎么分
→ 你自己觉得：
  → 上衣放一起
  → 裤子放一起
  → 内衣放一起
→ 这就是聚类！

例子 2：超市货架
→ 饮料放一区
→ 零食放一区
→ 日用品放一区
→ 自动分类！

Week1 的无监督学习算法：
✓ K-means（聚类）
```

### 知识点 2：四大算法对比

| 算法 | 核心思想 | 生活比喻 | 适用场景 | 优缺点 |
|------|----------|----------|----------|--------|
| **KNN** | 找最近的 K 个邻居投票 | 物以类聚，人以群分 | 小数据、简单分类 | ✓简单 ✗慢 |
| **决策树** | 问一系列问题做决定 | 20 个问题游戏 | 规则明确的分类 | ✓易解释 ✗易过拟合 |
| **随机森林** | 多棵树投票 | 专家会诊 | 复杂分类、防过拟合 | ✓准确 ✗黑盒 |
| **SVM** | 找最优分界线 | 拉警戒线 | 高维数据、小样本 | ✓理论强 ✗参数敏感 |

### 知识点 3：精确率 vs 召回率

**如何选择：**

🔹 **精确率（Precision）**
```
公式：预测为阳性的，真正阳性的比例

含义：你说的对不对
→ 眼光准不准
→ 宁可放过，不能误杀

使用场景：
✓ 垃圾邮件过滤
  → 宁可让垃圾邮件进来
  → 不能误杀重要邮件
  
✓ 推荐系统
  → 推荐的商品要精准
  → 不要乱推荐
```

🔹 **召回率（Recall）**
```
公式：真正阳性的，被找出的比例

含义：你找的齐不齐全
→ 覆盖面广不广
→ 宁可错杀，不能放过

使用场景：
✓ 癌症检测
  → 宁可误诊（让人复查）
  → 不能漏诊（耽误治疗）
  
✓ 地震预警
  → 宁可误报（疏散人群）
  → 不能漏报（造成灾难）
```

🔹 **F1 分数**
```
精确率和召回率的平衡

使用场景：
✓ 需要兼顾两者时
✓ 一般分类任务
✓ 没有特殊偏好时
```

### 知识点 4：过拟合和欠拟合

**过拟合 = 死记硬背**
```
表现：
✓ 训练集准确率很高（95%）
✓ 测试集准确率很低（50%）
✓ 差距很大

原因：
✗ 模型太复杂
✗ 把噪声也学进去了
✗ 只会做见过的题

生活例子：
→ 学生背答案
→ 练习题都会做
→ 题目一变就不会了

解决方法：
✓ 简化模型
✓ 增加数据
✓ 正则化
✓ Dropout
```

**欠拟合 = 不学习**
```
表现：
✓ 训练集准确率低（30%）
✓ 测试集准确率也低（30%）
✓ 都很差

原因：
✗ 模型太简单
✗ 根本没学会规律
✗ 连练习题都不会

生活例子：
→ 学生不学习
→ 练习题不会
→ 考试题也不会

解决方法：
✓ 增加模型复杂度
✓ 加特征
✓ 减少正则化
```

**正常拟合 = 真学会**
```
表现：
✓ 训练集准确率高（85%）
✓ 测试集准确率也高（82%）
✓ 差不多

原因：
✓ 模型适中
✓ 真正学会了规律
✓ 能举一反三

生活例子：
→ 学生理解方法
→ 练习题会做
→ 考试题也会
```

### 知识点 5：混淆矩阵

**TP/TN/FP/FN 详解：**

```
             预测阳性  预测阴性
实际阳性      TP       FN
实际阴性      FP       TN
```

🔹 **TP（真阳性）= 真病人，查出来了 ✅**
```
实际情况：有病
预测结果：说有病
→ 双正确！
→ 好事！
→ 及时发现病情
```

🔹 **TN（真阴性）= 真健康，也说健康 ✅**
```
实际情况：没病
预测结果：说没病
→ 双正确！
→ 好事！
→ 放心了
```

🔹 **FP（假阳性）= 其实健康，误诊有病 ❌**
```
实际情况：没病
预测结果：说有病
→ 误诊！
→ 虚惊一场
→ 要做进一步检查
→ 但比 FN 好
```

🔹 **FN（假阴性）= 真有病，说健康 ❌**
```
实际情况：有病
预测结果：说没病
→ 漏诊！
→ 危险！
→ 耽误治疗
→ 最严重的错误！
```

**记忆技巧：**
```
第一个字母：T=True（真），F=False（假）
第二个字母：P=Positive（阳性），N=Negative（阴性）

组合：
TP = 真的有，也说是
FN = 真的有，却说没
FP = 其实没，却说是
TN = 真的没，也说没
```
