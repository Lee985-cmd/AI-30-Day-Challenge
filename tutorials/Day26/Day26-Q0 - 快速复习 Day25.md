## 📚 Day25 核心知识点回顾

### 1. 语音识别基础

**声音的本质:**
- 空气振动产生的波
- 频率（音调高低）
- 振幅（声音大小）
- 数字化过程（采样、量化）

### 2. 语音识别流程

**传统 Pipeline:**
```
音频 → 预处理 → 特征提取 → 声学模型 → 解码器 → 语言模型 → 文本
```

**端到端架构:**
```
音频 → 神经网络 → 文本
```

### 3. 主流架构对比

| 架构 | 特点 | 适用场景 |
|------|------|----------|
| CTC | 流式，简单 | 实时识别 |
| Attention | 性能好 | 离线转写 |
| RNN-T | 流式+性能 | 移动端 |
| Conformer | 当前最佳 | 通用 |

### 4. Whisper 详解

**核心特点:**
- 68 万小时多语言数据
- 支持 99 种语言
- 强大的噪声鲁棒性
- 开源免费

**模型规格:**
- tiny: 39M 参数，最快
- base: 74M 参数，快
- small: 244M 参数，平衡
- medium: 769M 参数，高准确率
- large: 1550M 参数，最高准确率

### 5. 实战项目

**中文语音转文字系统:**
- 完整的项目结构
- 批量处理能力
- 多种输出格式（TXT/SRT/JSON/MD）
- 工程化实践

## 🔍 Day26 预习要点

### 强化学习是什么？

**定义：**
让智能体（Agent）通过与环境交互，根据奖励信号学习最优行为策略。

**核心概念：**
- Agent（智能体）：学习者
- Environment（环境）：Agent 所处的世界
- State（状态）：当前情况
- Action（动作）：可采取的行为
- Reward（奖励）：反馈信号

### 与其他 ML 的区别

**监督学习：**
- 输入 → 输出
- 有标准答案
- 分类、回归任务

**无监督学习：**
- 发现数据内在结构
- 无标签数据
- 聚类、降维任务

**强化学习：**
- 状态 → 动作 → 奖励
- 通过试错学习
- 决策、控制任务

### 强化学习的应用

1. **游戏 AI**
   - AlphaGo
   - Atari 游戏
   - MOBA 游戏

2. **机器人控制**
   - 自主导航
   - 抓取物体
   - 平衡控制

3. **自动驾驶**
   - 路径规划
   - 决策控制
   - 安全驾驶

4. **推荐系统**
   - 个性化推荐
   - 广告投放
   - 内容排序

### 主要算法

1. **Q-Learning**
   - 基础算法
   - 值函数学习
   - 适用于离散状态

2. **Deep Q-Network (DQN)**
   - 深度学习 + Q-Learning
   - 处理连续状态
   - 经验回放

3. **策略梯度**
   - 直接优化策略
   - 适用于连续动作
   - Actor-Critic
