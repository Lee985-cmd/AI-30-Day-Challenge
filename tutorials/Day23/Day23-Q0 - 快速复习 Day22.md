## 📚 Day22 核心知识点回顾

### 1. Transformer 架构的重要性

**为什么 Transformer 如此重要？**
- 解决了 RNN/LSTM 的串行计算问题
- 实现了并行化训练，速度提升 10-100 倍
- 能够捕捉长距离依赖关系
- 开启了大语言模型时代

### 2. Self-Attention 机制

**核心公式：**
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

**关键组件：**
- Query (Q): 查询向量，表示"我想找什么"
- Key (K): 键向量，表示"我有什么"
- Value (V): 值向量，表示"我能提供什么"
- Scaled Dot-Product: 防止梯度消失

### 3. Multi-Head Attention

**优势：**
- 多个注意力头可以关注不同的信息
- 增强模型的表达能力
- 每个头学习不同的特征表示

### 4. Positional Encoding

**作用：**
- 为序列中的每个位置提供唯一标识
- 让模型理解词语的顺序关系
- 使用正弦和余弦函数生成位置编码

### 5. Encoder-Decoder 架构

**Encoder:**
- 理解输入序列的语义
- 生成上下文相关的表示

**Decoder:**
- 自回归生成输出序列
- 使用 Masked Attention 防止看到未来信息

## 🔍 Day23 预习要点

### BERT 的核心创新

1. **双向 Transformer**
   - 同时考虑左右上下文
   - 比单向模型更好地理解语义

2. **Masked Language Model (MLM)**
   - 随机遮蔽部分词汇
   - 让模型预测被遮蔽的词

3. **Next Sentence Prediction (NSP)**
   - 判断两个句子是否连续
   - 学习句子间关系

### 预训练 + 微调范式

**预训练阶段：**
- 在大规模无标注数据上学习
- 掌握语言的通用知识

**微调阶段：**
- 在小规模有标注数据上调整
- 适应特定任务需求
