## ❌ 常见错误

### 错误 1：看不懂坐标轴 ❌

**错误表现：**
```
✗ 不知道横轴竖轴代表什么
✗ 分不清左右上下
```

**正确做法：**
```
✓ 先解释坐标轴
✓ 用手指着说方向
✓ "越往右越...，越往上越..."
```

---

### 错误 2：不理解距离的概念 ❌

**错误表现：**
```
✗ 以为距离就是空间远近
✗ 不知道是数值差异
```

**正确理解：**
```
✓ 距离 = 特征差异的大小
✓ 数值越接近，距离越近
✓ 不是眼睛看到的远近
✓ 是数学计算的远近
```

---

### 错误 3：忽略 K 值的作用 ❌

**错误表现：**
```
✗ 不说 K=3 是什么意思
✗ 不明白为什么要数 3 个
```

**正确做法：**
```
✓ 说明 K=3 就是问 3 个邻居
✓ 用手指着图数出来
✓ "你看这 1 个、这 1 个、还有这 1 个"
```

## 🔍 代码示例

### 绘制这张图的代码

```python
import matplotlib.pyplot as plt

# ========== 准备数据 ==========
# 苹果的数据（红色圆点）
apple_x = [150, 160, 140]    # 重量
apple_y = [7, 8, 6]          # 甜度

# 柠檬的数据（黄色三角）
lemon_x = [50, 60, 55]       # 重量
lemon_y = [3, 2, 4]          # 甜度

# 新水果的数据（绿色星星）
new_x = [155]                # 重量
new_y = [7.5]                # 甜度

# ========== 画图 ==========
plt.figure(figsize=(8, 6))  # 设置图的大小

# 画苹果（红色圆点）
plt.scatter(apple_x, apple_y, 
           c='red',           # 红色
           s=100,             # 点的大小
           label='苹果',       # 标签
           marker='o')        # 圆形标记

# 画柠檬（黄色三角）
plt.scatter(lemon_x, lemon_y, 
           c='yellow',        # 黄色
           s=100,             # 点的大小
           label='柠檬',       # 标签
           edgecolors='black', # 黑色边框
           marker='^')        # 三角形标记

# 画新水果（绿色星星）
plt.scatter(new_x, new_y, 
           c='green',         # 绿色
           s=200,             # 星星大一点
           label='新水果',     # 标签
           marker='*',        # 星星标记
           edgecolors='black') # 黑色边框

# ========== 美化图表 ==========
plt.xlabel('重量（克）', fontsize=12)      # x 轴标签
plt.ylabel('甜度（1-10）', fontsize=12)    # y 轴标签
plt.title('K 近邻算法示意图（K=3）', fontsize=14)  # 标题
plt.legend()        # 显示图例
plt.grid(True, alpha=0.3)  # 显示网格
plt.show()          # 显示图表

# ========== 打印说明文字 ==========
print("看图说明：")
print("✓ 红色圆点 = 苹果（训练数据）")
print("✓ 黄色三角 = 柠檬（训练数据）")
print("✓ 绿色星星 = 新水果（要预测的）")
print("\n可以看到：")
print("新水果离苹果更近")
print("所以它应该是苹果！🍎")
```
