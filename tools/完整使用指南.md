# 🚀 Markdown 转公众号工具 - 完整使用指南

## 📖 功能总览

### ✅ 已实现功能

1. **多主题支持** - 5种精美主题（默认/浅色/深色/彩色/极简）
2. **表格格式化** - 自动将 Markdown 表格转为 HTML 表格
3. **数学公式** - 基础 LaTeX 符号支持（α, β, ∑, ∫等）
4. **图片处理** - 图片占位符提示（需手动上传到公众号）
5. **GUI 界面** - 图形化操作，无需命令行
6. **批量转换** - 一键转换所有文章
7. **实时预览** - 转换前预览效果

## 💻 使用方法

### 方法 1：GUI 界面（推荐新手）

```bash
python tools\md_to_wechat_gui.py
```

**操作步骤：**
1. 点击"浏览..."选择输入文件
2. 选择输出文件路径（可选）
3. 选择主题风格
4. 点击"🔄 预览转换"查看效果
5. 点击"✅ 开始转换"生成文件
6. 用浏览器打开 HTML 文件
7. 全选复制到公众号编辑器

### 方法 2：命令行（推荐批量处理）

#### 单文件转换

```bash
# 基本用法
python tools\md_to_wechat_enhanced.py article.md

# 指定主题
python tools\md_to_wechat_enhanced.py article.md -t light

# 指定输出文件
python tools\md_to_wechat_enhanced.py article.md -o output.html -t dark
```

#### 批量转换

```bash
# 运行批量转换脚本
batch_convert_all.bat

# 然后选择主题即可
```

#### 查看所有主题

```bash
python tools\md_to_wechat_enhanced.py --list-themes
```

### 方法 3：快捷脚本

```bash
# 使用旧版转换工具（兼容）
convert.bat "promotion-articles\文章名.md"
```

## 📝 支持的格式

### ✅ 完全支持

| 格式 | Markdown 语法 | 说明 |
|------|--------------|------|
| 标题 | `#` `##` `###` | 三级标题，不同大小和颜色 |
| 加粗 | `**text**` | 粗体显示 |
| 斜体 | `*text*` | 斜体显示 |
| 列表 | `- item` | 无序列表，带项目符号 |
| 引用 | `> text` | 引用块，左侧彩色边框 |
| 代码块 | ` ```code``` ` | 深色背景，等宽字体 |
| 分隔线 | `---` | 水平分割线 |
| 链接 | `[text](url)` | 可点击链接 |
| 表格 | `\|col1\|col2\|` | 完整表格，带表头 |
| 图片 | `![alt](path)` | 占位符提示 |
| 数学公式 | `$formula$` | 基础 LaTeX 符号 |

### 📊 表格示例

**Markdown 输入：**
```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| Lee | 30 | 北京 |
| Alice | 25 | 上海 |
```

**转换后效果：**
- 自动识别表头和数据行
- 交替行背景色
- 响应式设计，移动端友好

### 🔢 数学公式示例

**Markdown 输入：**
```markdown
$$ E = mc^2 $$

$$ \sum_{i=1}^{n} x_i $$

$$ \alpha + \beta = \gamma $$
```

**支持的符号：**
- 希腊字母：α, β, γ, δ, ε, θ, λ, μ, π, σ, ω
- 数学符号：∑, ∫, ∞, ≠, ≤, ≥, ≈, ×, ÷, ±, √
- 上下标：x², x³, H₂O

## 🎯 最佳实践

### 1. 选择合适的主题

- **技术文章** → default 或 dark
- **生活分享** → light 或 colorful
- **文学创作** → minimal
- **教程文档** → default

### 2. 写作规范

```markdown
# 大标题（文章标题）

## 二级标题（章节标题）

### 三级标题（小节标题）

正文段落，保持简洁明了。

- 使用列表突出重点
- **加粗**关键信息
- *斜体*强调术语

> 引用重要观点或他人话语

```python
# 代码示例要完整可运行
def example():
    print("Hello")
```

| 表格 | 用于数据对比 |
|------|-------------|
| 行1  | 数据1       |
```

### 3. 图片处理

由于公众号需要手动上传图片，建议：

1. 在 Markdown 中保留图片标记
2. 转换后会在 HTML 中显示占位符
3. 在公众号编辑器中手动上传图片
4. 替换占位符为实际图片

### 4. 批量工作流

```bash
# 1. 写完所有文章后
# 2. 运行批量转换
batch_convert_all.bat

# 3. 选择一个主题（如 default）
# 4. 等待所有文件转换完成
# 5. 逐个检查并粘贴到公众号
```

## 🔧 自定义主题

编辑 `tools/md_to_wechat_enhanced.py` 中的 `THEMES` 字典：

```python
THEMES = {
    "my_theme": {
        "name": "我的主题",
        "colors": {
            "primary": "#FF0000",      # 标题颜色
            "secondary": "#00FF00",    # 副标题颜色
            "accent": "#0000FF",       # 强调色
            "text": "#333333",         # 正文颜色
            "code_bg": "#F5F5F5",      # 代码背景
            "code_text": "#000000",    # 代码文字
            "quote_bg": "#FAFAFA",     # 引用背景
            "border": "#E0E0E0",       # 边框颜色
        },
        "fonts": {
            "title_h1": "24px",
            "title_h2": "20px",
            "title_h3": "17px",
            "body": "16px",
            "code": "14px",
            "line_height": "2.0",
        }
    }
}
```

然后使用：
```bash
python tools\md_to_wechat_enhanced.py article.md -t my_theme
```

## ❓ 常见问题

### Q1: GUI 界面打不开？

A: 确保已安装 Python 和 Tkinter：
```bash
python -m tkinter  # 测试 Tkinter 是否正常
```

### Q2: 转换后格式不对？

A: 检查：
1. Markdown 语法是否规范
2. 代码块是否正确闭合（三个反引号）
3. 表格格式是否正确

### Q3: 如何调整样式细节？

A: 修改 `md_to_wechat_enhanced.py` 中对应方法的样式字符串。

### Q4: 支持更多 LaTeX 公式吗？

A: 当前仅支持基础符号。如需完整支持，需要集成 MathJax 或 KaTeX。

### Q5: 图片能自动上传吗？

A: 目前不支持。公众号图片需要手动上传到素材库。

### Q6: 可以导出为其他格式吗？

A: 当前仅支持 HTML。如需 PDF/Word，可使用其他转换工具。
