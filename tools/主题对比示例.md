## 使用说明

### 命令行方式

```bash
# 使用默认主题
python tools/md_to_wechat_enhanced.py article.md

# 使用浅色主题
python tools/md_to_wechat_enhanced.py article.md -t light

# 使用深色主题
python tools/md_to_wechat_enhanced.py article.md -t dark

# 使用彩色主题
python tools/md_to_wechat_enhanced.py article.md -t colorful

# 使用极简主题
python tools/md_to_wechat_enhanced.py article.md -t minimal

# 查看所有主题
python tools/md_to_wechat_enhanced.py --list-themes
```

### GUI 方式

```bash
python tools/md_to_wechat_gui.py
```

然后在图形界面中选择：
1. 输入文件
2. 输出文件
3. 主题风格
4. 点击"开始转换"

## 主题特点总结

### 🎨 default（默认主题）
- **特点**：平衡、专业
- **适用**：技术文章、教程
- **配色**：深蓝色调

### ☀️ light（浅色主题）
- **特点**：清新、明亮
- **适用**：日常分享、生活类
- **配色**：浅灰色调

### 🌙 dark（深色主题）
- **特点**：护眼、现代
- **适用**：夜间阅读、开发者
- **配色**：深色背景

### 🌈 colorful（彩色主题）
- **特点**：活泼、有趣
- **适用**：创意内容、年轻人
- **配色**：多彩搭配

### ⚪ minimal（极简主题）
- **特点**：简洁、纯粹
- **适用**：文学、哲学类
- **配色**：黑白为主
